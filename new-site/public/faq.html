免费节点与赞助

怎么通过邮件领取节点？
打不开本站或 GitHub 时，发任意内容的邮件到 end.gfw01@gmail.com，系统会自动回复节点。如果这个邮箱被封，可以发到 yumenglong1989@gmail.com 或 huchenfeng1989@gmail.com。为防止滥用，6 小时内只回复一次；收不到请检查垃圾邮件，或换一个邮箱再发。邮件领取的节点到期后需要到 签到 页做邮箱签到，才会继续收到节点。
免费节点怎么用？
在 首页 复制免费订阅链接导入客户端，或复制单个 VLESS / ss:// 节点，也可以用客户端扫二维码。节点换 IP 后订阅会自动更新，在客户端里点“更新订阅”即可。免费节点多人共用，速度有限；每一份赞助都会用来增加更多免费节点。
免费节点、赞助线路和免费软件有什么区别？
免费软件由第三方提供，速度和稳定性不固定。免费节点和赞助线路都是我们自己的节点，免费节点多人共享带宽，赞助线路按赞助档位提供更高的速度，支持 VLESS REALITY、Hysteria2 和 Shadowsocks，节点被封会自动换 IP。一个订阅链接可以同时在手机和电脑上使用。
怎么付款？会自动扣费吗？
在 赞助支持 选择档位后跳转到 Stripe 付款页，可用银行卡等方式付款（以付款页显示为准）。每次付款 30 天，不会自动续费。本站看不到你的卡号。
订阅 token 是什么？丢了怎么办？
订阅链接里 token= 后面的那一串就是 token，等同于你的账号，请不要分享给别人。付款成功页和邮件里都有完整的订阅链接；在 我的订阅 粘贴链接或 token 就能查看。如果都找不到了，请用付款时的邮箱发邮件到 end.gfw@hotmail.com。
怎么续费？提前续费会不会浪费？
在 我的订阅 点“续费 / 升级”，或在套餐页选择“续费已有订阅”并填 token。到期前续费会在原到期时间上加 30 天，不会浪费；到期前买了更低的套餐会保持原来较高的速度。
“签到”是做什么的？

在 签到 页有两种签到，每次都从签到当天起延长 4 天，已经过期的也可以直接签到恢复；剩余时间多于 4 天时签到不会改变到期时间。

订阅链接 ID 签到：订阅链接到期后，签到即可继续使用同一条链接，新旧系统的订阅都可以。

邮箱签到：通过邮件领取节点的用户，到期后系统不再给这个邮箱发送节点；签到后恢复。

连不上了 / 订阅更新失败怎么办？

1. 先在客户端里“更新订阅”，节点换 IP 后需要更新才能拿到新地址。

2. 订阅本身打不开时，用 我的订阅 里的“备用链接”重新导入。

3. 换一种协议试试：Hysteria2 在丢包多的网络更快，VLESS REALITY 更不容易被识别。

4. 仍然不行，请发邮件到 end.gfw@hotmail.com，附上 token（免费节点不用）和客户端名称。

客户端导入订阅

Hiddify（Android / iOS / Windows / Mac）
  1. 复制“V2Ray / Hiddify”订阅链接。
  2. 打开 Hiddify，点右上角“+”（新建配置）。
  3. 选择“从剪贴板添加”，然后点中间的连接按钮。
  4. 切换节点：在“代理”页选择；以后点“更新”即可刷新节点。
v2rayN（Windows）/ v2rayNG（Android）
  1. 复制“V2Ray”订阅链接。
  2. v2rayN：订阅分组 → 订阅分组设置 → 添加，粘贴链接后确定；v2rayNG：右上角菜单 → 订阅分组设置 → “+”，粘贴链接后保存。
  3. 回到主界面选择“更新订阅”，选一个节点后开启代理。
Clash Verge / Clash Meta（Windows / Mac / Linux）
  1. 复制“Clash”订阅链接（注意不是 V2Ray 链接）。
  2. 打开“订阅”页，粘贴链接后点“导入”。
  3. 选中这个订阅，在“代理”页选择节点，打开“系统代理”。
Karing（Android / iOS / Windows / Mac）
  1. 复制“V2Ray”订阅链接。
  2. 打开 Karing：我的配置 → “+” → 添加配置链接，粘贴后保存。
  3. 回到首页点连接。
Shadowrocket（iPhone / iPad）
  1. 需要非中国大陆区的 Apple ID 才能下载，见 软件下载。
  2. 复制“V2Ray”订阅链接，打开 Shadowrocket 通常会自动识别并提示添加；没有提示就点右上角“+”，类型选 Subscribe，粘贴链接。
  3. 选择节点后打开顶部开关。
Outline（所有平台）
  1. 复制“Outline”链接（以 ssconf:// 开头）。
  2. 打开 Outline，点“+”添加服务器，粘贴访问密钥。
  3. Outline 会自动跟随节点换 IP，不需要手动更新。

安全

你们会记录我访问了什么吗？
网站不保存访问日志。节点只按用户统计流量总量，用于限速和套餐管理，不记录你访问的网站。付款信息由 Stripe 处理。详见 隐私政策。
用国内邮箱安全吗？
国内邮箱可能被监控，建议使用 Gmail、Outlook、Proton 等海外邮箱接收订阅链接。
