翻墙常用小工具

二维码、订阅转换、Base64……全部在你的浏览器里运行，本站不会把你输入的内容发到任何服务器（节点链接、订阅内容也一样）。页面上有 Google 广告；处理节点链接等敏感内容时，可以打开页面后先断网再用，工具照样能用。

二维码生成

把节点链接、订阅链接或任意文字变成二维码，用手机客户端扫码导入（v2rayNG、Shadowrocket、Hiddify 等都支持扫码）。

二维码识别

从截图或照片里读出二维码内容（比如 YouTube 直播画面里的节点二维码、别人发来的图片）。图片只在本机处理，不上传。

订阅 / 配置转换

把订阅内容（base64）或一行一个的节点链接，转换成 Clash（Clash Verge / mihomo）配置、base64 订阅或明文链接。支持 VLESS（含 REALITY）、VMess、Trojan、Shadowsocks、Hysteria2。

怎么拿到订阅内容：用浏览器打开订阅链接，全选复制页面上的那一大段文字，粘贴到下面。网页不会替你去下载订阅链接（那样服务器就能看到你的订阅）。

Clash 配置里已经带上防 DNS 泄漏的设置（fake-ip + 加密 DNS），见 怎么防止 DNS 泄漏。“国内直连”用到 GeoIP，客户端第一次启动时可能要下载 GeoIP 数据库，下载不了就先选“全部走代理”。

Base64 编码 / 解码

解码订阅内容、ss:// 链接里的加密方式和密码等。自动兼容 URL 安全格式（- _）、缺少的 = 和换行；按 UTF-8 处理中文。

URL 编码 / 解码

节点链接 # 后面的名字、参数里的中文常被编码成 %E4%B8%AD 这样，解码后就能看懂。

文件校验（SHA-256）

下载的安装包有没有被调包？算出文件的 SHA-256，和软件官网或 GitHub Release 页面上写的值对比，一致才安全。文件不上传，在本机计算。

随机密码 / UUID

用浏览器的安全随机数生成。自己搭节点时可用作 Shadowsocks 密码、VLESS/VMess 的 UUID、Hysteria2 密码。
